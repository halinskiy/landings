# Landings

A collection of landing-page experiments. Each subfolder is a self-contained static export deployed via GitHub Pages.

## Index

- **[LOUD](./LOUD/)** — Maximalist persona / typeface release for *MERIDA* by Recension Type Co. Multi-colour, motion-heavy, broken grid, custom cursor. Live: <https://halinskiy.github.io/landings/LOUD/>
- **[nocorny](./nocorny/)** — Webflow studio landing in LOUD aesthetic. Card-flip services, scramble-decode headlines, 3D tilt process steps, pointer-tracking browser previews, dual marquee. Live: <https://halinskiy.github.io/landings/nocorny/>
